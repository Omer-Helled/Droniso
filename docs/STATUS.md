## מה עדיין זמני

- **התמונות והסרטונים בגלריה מגיעים עדיין מהשרתים של Wix.** אל תבטל את Wix עד ששלב 3 גמור. שם הם עוברים ל-Supabase, וזה שינוי בקובץ אחד: `lib/media-url.ts`.
- **הטופס**: כרגע, אחרי מילוי, הוא מכין את ההודעה ושולח אותה בוואטסאפ או במייל. בשלב 3 הוא ישמור את הפנייה ב-Supabase וישלח לך מייל אוטומטית.
- **הצהרת הנגישות ומדיניות הפרטיות** הן טיוטות (`content/legal.ts`). כדאי שמישהו מוסמך יעבור עליהן לפני ההשקה. בחרתי זמן שמירה של 24 חודשים לפניות, ואפשר לשנות.

## מה צריך ממך לשלב 3

1. **חשבון Supabase**: נכנסים ל-supabase.com, יוצרים פרויקט, ושולחים לי את ה-Project URL ואת ה-anon key. **את ה-service role key לא שולחים בצ'אט**: מכניסים אותו בעצמך ב-Vercel.
2. **חשבון Vercel**: מחברים את הריפו (ההוראות למטה).
3. **מייל לקבלת פניות**: dronisoil@gmail.com או כתובת אחרת? בשביל שליחה אוטומטית נשתמש ב-Resend, שיש לו שכבה חינמית.

## איך לראות את האתר

**ב-Vercel:**
1. נכנסים ל-vercel.com ומתחברים עם GitHub.
2. Add New → Project → בוחרים את `Droniso`.
3. Deploy. אין צורך במשתני סביבה בשלב הזה.
4. כל push לענף `claude/portfolio-redesign-modern-kgw5uw` יוצר כתובת תצוגה חדשה.

**במחשב:**
```bash
npm install
npm run build && npm start
```

ואז לבדיקת התוכן, בטרמינל נוסף:
```bash
npm run verify -- http://localhost:3000
```
