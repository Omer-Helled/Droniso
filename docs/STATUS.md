# סטטוס האתר

> **שלבים 0 עד 3 הושלמו והאתר באוויר: https://droniso.vercel.app**
> האתר עומד בפני עצמו: הוא לא טוען שום דבר מ-Wix, והטופס שולח מייל דרך Resend (המפתח מוגדר ב-Vercel).
> הבא בתור: שלב 4 (מעבר שלך על האתר והערות) ושלב 5 (חיבור הדומיין והשקה).

## מה השתנה בשלב 3

**בלי Supabase.** בחשבון החינמי לא היה מקום לפרויקט נוסף, פרויקט חינמי מושהה אחרי שבוע בלי פעילות, ומכסת התעבורה שלו קטנה לסרטונים. במקום זה:

| מה | איך זה עובד עכשיו |
|---|---|
| תמונות | כל 62 הפריטים עובדו מקובצי המקור לגרסאות AVIF ב-3 עד 5 רוחבים, עם JPEG לדפדפנים ישנים. הקבצים יושבים באתר עצמו (`public/media/v1`) ומוגשים מה-CDN של Vercel |
| סרטונים | 11 הסרטונים קודדו מחדש בשתי גרסאות: מלאה לתצוגה המוגדלת, וקלה לתצוגה המקדימה ולטלפונים |
| טופס צור קשר | נשלח לשרת האתר (`/api/contact`), נבדק שם שוב, ונשלח אליך במייל דרך Resend. כפתור "השב" במייל עונה ישר ללקוח |
| אם המייל לא נשלח | הטופס מציג את ההודעה המוכנה עם כפתורי וואטסאפ ומייל, כך שפנייה לא הולכת לאיבוד. זה גם מה שקורה עד שמגדירים את מפתח Resend |
| הגנה מספאם | שדה מלכודת, בדיקת זמן מילוי, חסימת שליחה מאתרים אחרים, והגבלת קצב |

הפניות **לא נשמרות במסד נתונים**. הן מגיעות למייל שלך בלבד.

בדרך תוקנו גם שני באגים:
- בתצוגה המוגדלת, תמונות אנכיות גלשו מתחת לקצה המסך במחשב.
- באתר החי ב-Vercel, מעבר לעמוד הבית בעברית גרם לטעינה מלאה של הדף ולשגיאות ברקע. הסיבה: העמודים בעברית הוגשו דרך כלל ניתוב (rewrite). עכשיו העברית והאנגלית הן נתיבים רגילים (`app/(he)` ו-`app/en`), בלי כללי ניתוב, והמעבר בין עמודים מיידי בשתי השפות.

## מה צריך ממך

### 1. לוודא שמייל הבדיקה הגיע

מפתח Resend מוגדר ב-Vercel ועובד: ב-16.11.2026 נשלחה מהאתר החי פניית בדיקה, ו-Resend אישר שקיבל אותה. נשאר לוודא שהיא הגיעה לתיבה של dronisoil@gmail.com. הנושא: "פנייה חדשה מהאתר: בדיקה אוטומטית". אם היא בספאם, לסמן "לא ספאם".

השכבה החינמית של Resend מאפשרת 100 מיילים ביום. אחרי שהדומיין droniso.com יחובר, אפשר לאמת אותו ב-Resend, ואז המיילים יישלחו מכתובת של הדומיין ויגיעו גם לכתובות אחרות.

### 2. לשמור עותק של קובצי המקור לפני שמבטלים את Wix

האתר כבר לא תלוי ב-Wix, אבל **קובצי המקור ברזולוציה מלאה** (365MB) נמצאים רק שם. בריפו נשמרות רק הגרסאות המוקטנות. לפני ביטול Wix, צריך להוריד את קובצי המקור לדיסק או ל-Google Drive: ב-Wix, ב-Media Manager, מסמנים הכול ומורידים. מי שיש לו Node במחשב יכול להריץ `node scripts/backup-wix-media.mjs`.

### 3. הדומיין

droniso.com מחזיר כרגע שגיאה. צריך לבדוק ב-Wix, בחלק של הדומיינים, אם הוא רשום על שמך ועד מתי. בשלב ההשקה נחבר אותו ל-Vercel.

### 4. לפני ההשקה

- **Vercel Pro** (בערך $20 לחודש): החשבון החינמי לא מיועד לאתרים עסקיים.
- **הצהרת הנגישות ומדיניות הפרטיות** הן טיוטות (`content/legal.ts`). כדאי שמישהו מוסמך יעבור עליהן.

## מה עוד לא קיים

- **ממשק ניהול.** הוספת עבודה חדשה דורשת כרגע שינוי בקוד. ממשק שבו תעלה עבודות בעצמך הוא שלב 6, והוא ידרוש אחסון ומסד נתונים.
- **מדידת גולשים** (Vercel Analytics) תופעל בהשקה.

```bash
npm install
npm run build && npm start
```

ואז לבדיקת התוכן, בטרמינל נוסף:
```bash

```
